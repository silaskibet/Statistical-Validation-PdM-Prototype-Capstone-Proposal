# Statistical Validation, PdM Prototype & Capstone Proposal

This repository contains the deliverables for the Week 6 assignment of the Inuka Tech Fellowship. The project focuses on statistical validation, feature engineering for Predictive Maintenance (PdM), predictive modeling, and cross-functional technical communication. 

The capstone proposal centers on transitioning logistics fleet vehicles from calendar-based maintenance to dynamic, risk-based scheduling utilizing operational telematics.
